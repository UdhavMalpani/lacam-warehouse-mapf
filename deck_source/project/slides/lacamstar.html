Background · LaCAM* (Okumura, IJCAI 2023)

LaCAM* adds two upgrades

inside PIBT

Swap technique

When two agents meet head-on in a corridor, PIBT cannot let them pass. The swap rule detects this and pulls one agent back to the nearest junction so the pair can exchange places.

Matters in 1-wide aisles and dead ends.

on top of the search

Anytime refinement

After the first solution the search continues. Revisits re-wire the explored graph with Dijkstra-style cost updates, and nodes that cannot beat the incumbent are pruned.

Eventually optimal, given time and memory.

Plus 0.1 % random restarts. In the main benchmark every planner returns its first solution; refinement is studied separately.

LaCAM* keeps LaCAM's structure and adds two things. First, a swap technique inside PIBT: in a corridor two agents moving towards each other block each other forever, because PIBT never lets an agent move into the cell of the agent that pushed it. The swap rule checks whether a swap is both needed and possible, and if so lets the agent be pulled back to a branching vertex so the two can pass. Second, anytime refinement: configurations get costs (sum of loss), the explored graph is re-wired when a cheaper path to a known configuration is found, and the search prunes nodes whose lower bound cannot beat the current solution. That makes it eventually optimal. For a fair comparison, the main benchmark uses LaCAM*'s first solution, since EECBS, PBS and LNS2 also stop at their first solution.
