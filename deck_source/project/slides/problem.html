The problem

Hundreds of robots, one shared floor

Multi-agent path finding (MAPF)

  • A grid map; N agents, each with a start and a goal cell
  • Every timestep each agent moves to a neighbouring cell or waits
  • Never two agents in one cell, never two agents swapping along an edge
  • Plan for everyone to reach their goal; measure the sum of arrival times (sum-of-costs)

Why warehouses make it hard

  • Minimising sum-of-costs is NP-hard, so optimal planners stop scaling at modest team sizes
  • Fulfilment and sortation centres run hundreds to thousands of robots
  • Shelving creates 1-wide aisles and dead ends where robots meet head-on
  • Plans must come in fractions of a second, not minutes
MAPF: given a graph and N agents with start and goal vertices, find a collision-free plan. Conflicts are vertex conflicts (two agents in one cell) and swap conflicts (two agents exchanging positions along one edge); following and rotations are allowed. Quality is measured as sum-of-costs: each agent's cost is the time it finally arrives at its goal. Warehouses are the motivating application: many robots, narrow aisles and dead ends, and a need for very fast planning.
