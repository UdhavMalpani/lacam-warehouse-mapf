385 solved before a baseline solves its first

Each curve: how many instances a planner solves if given that much time. On warehouse maps the first baseline solution arrives at 83 ms; by then LaCAM* has solved 385 of 560.

This is the classic cactus plot: for every time budget on the x axis (log scale), how many instances each planner would have solved. LaCAM, PIBT and LaCAM* sit two orders of magnitude to the left of the search and LNS baselines. On warehouse maps the earliest any baseline solves an instance is 83 milliseconds; by that point LaCAM* has already solved 385 of the 560 warehouse instances, and 557 within one second. Note that PIBT and LaCAM plateau early: once they fail, more time does not help (PIBT livelocks; LaCAM's search space explodes in narrow aisles). The baselines are still climbing at 30 s, so a longer time limit would help them, but not enough to close the gap at 1,000 agents.
