Experimental setup

12 maps, up to 1,000 agents, 7 planners

Protocol

  • Official code for EECBS, MAPF-LNS2, PBS; same compiler for all
  • 30 s per run; first solution counts
  • 10 scenarios per point on warehouses, 5 elsewhere
  • 760 instances per planner, 4,500 runs executed
  • Every solution re-checked; 0 invalid
The warehouse settings are the four MovingAI warehouse maps (small and large, 1-wide and 2-wide aisles) plus three layouts I generated: a sortation floor (2 by 2 chute blocks separated by 1-wide lanes), a very-narrow-aisle racking area where every aisle is a dead end, and an open cross-dock floor. The other domains are standard MovingAI maps: random obstacles, rooms, a maze, a game map and a city map. Agent counts go up to 1,000 (400 and 350 on the two small maps). Every planner ran on the same instances with a 30 second limit and returns its first solution. If a planner solved none of the instances at some agent count, larger counts on that map were counted as failures without running them (820 of the 5,320 planner-instance pairs). All solutions were re-validated by one independent checker and all costs recomputed the same way.
