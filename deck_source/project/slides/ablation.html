Inside LaCAM · ablation

Search and swap fix different failures

1-wide aisles, maze

Swap does it. warehouse-10-20-10-2-1: PIBT 5 %, with swap 98 %, LaCAM 25 %.

random obstacles

Search does it. PIBT with swap 92 %, LaCAM 100 %.

dead-end aisles

Both are needed. With swap 62 %, LaCAM 0 %, LaCAM* 100 %.

All four columns run the same PIBT code; they differ only in whether the swap technique is on and whether LaCAM's search is on top. In corridor-like layouts (1-wide warehouse aisles, the sortation lanes, the maze) the dominant failure is two agents meeting head-on, and the swap technique alone fixes it: on warehouse-10-20-10-2-1 plain PIBT solves 5%, PIBT with swap 98%, while LaCAM's search without swap only gets to 25% because the corridor deadlock makes its search space explode. On random obstacles the failure is a different kind of cycle that the swap rule cannot break, and the search fixes it: 92% versus 100%. On the dead-end aisle layout you need both: PIBT with swap 62%, LaCAM 0%, LaCAM* 100%. So LaCAM*'s robustness comes from the combination.
