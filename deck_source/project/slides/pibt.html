Background · PIBT (Okumura et al., 2019 / 2022)

PIBT plans one timestep at a time

1 · priorities

Longest-waiting first

An agent's priority grows every step it is away from its goal and resets once it arrives.

2 · inheritance

Push the blocker

If my best next cell is occupied, its occupant inherits my priority and must move out first, recursively.

3 · backtracking

Try the next cell

If the occupant cannot move, I fall back to my next-best cell, ending with waiting in place.

Fast (one step for all agents in roughly linear time) but incomplete: agents can circle forever a few cells from their goals. Run alone, it solved 411 of our 760 instances.

PIBT decides only the next step for all agents. Agents are ordered by priority; the highest-priority agent picks its best neighbouring cell by distance to goal. If that cell is occupied by an agent that has not moved yet, that agent inherits the priority and must vacate first. If it cannot, the original agent backtracks to its next option. This gives one valid joint move in roughly linear time per step, which is why it scales to thousands of agents. But it is myopic: in our benchmark plain PIBT solved only 411 of 760 instances (54%) because it livelocks, which a later slide shows directly.
